# Бюро космонавтики — фронтэнд

Полностью отдельный проект: React + Vite + Tailwind, компоненты в стиле shadcn.
Общается с бэкэндом только через REST (`/api` проксируется на `:8004`).

## Запуск

```bash
pnpm install
pnpm dev        # http://localhost:5173, бэкэнд должен слушать :8004
```

## Страницы

- `/` — лендинг: Земля и станции, вращающиеся по тонким линиям орбит
- `/cosmonauts` — отряд с аватарками и поиском (имя, страна, знак зодиака, локация)
- `/earth` — живая карта: станции и ракеты иконками, клик → страница объекта
- `/stations/:id`, `/rockets/:id` — детали: live-миникарта, люди на борту
  (тот же элемент списка, что в отряде), связанные миссии
- `/missions` — канбан с перетаскиванием карточек между статусами
- `/hangar` — склад с N типами ракет (кнопки постройки с эффектом сборки),
  выше — флот, сгруппированный по статусам

## Как движется карта

`GET /map` отдаёт угол и период каждого объекта на момент запроса; дальше
позиции пропагируются на клиенте (`requestAnimationFrame`, время ускорено
в 120 раз, чтобы движение было видно глазом) — без повторных запросов.
