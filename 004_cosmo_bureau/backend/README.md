# Бюро космонавтики им. Героя России Синса — бэкэнд

Модули обеспечения полётов и нахождения космонавтов.

## Архитектура

Чистая слоёная архитектура **без интерфейсов БД** — сервисы зависят от
конкретных SQLAlchemy-репозиториев:

```
VIEWS (app/views)  — HTTP: роутеры, схемы запросов, коды ответов
CORE  (app/core)   — бизнес-логика: сервисы, доменные модели, орбиты, зодиак
REPO  (app/repository) — SQLAlchemy: таблицы и конкретные репозитории
```

Транзакция — на весь HTTP-запрос (`views/deps.py`): репозитории не коммитят,
поэтому составные операции («списать ресурсы + создать ракету») атомарны.

## Домен

- **Космонавты** — страна, дата рождения; знак зодиака вычисляется, не хранится.
  Локация: на Земле / в ракете / на станции.
- **Станции** — фиксированная круговая орбита (радиус, фаза, эпоха); период — по
  третьему закону Кеплера, координаты рассчитываются в момент обращения.
  Кислород 0..1.
- **Ракеты** — N типов (сид: грузовой «Протон-ГК» 2 т говна + 3 т палок,
  пассажирский «Союз-ПК» 5 т говна + 4 т палок). Постройка списывает ресурсы.
  Непереиспользуемые: `created -> flying -> docked -> descending -> landed`.
- **Миссии** — канбан `open / taken / done / cancelled`; груз и/или экипаж,
  награда зачисляется в «кредиты» после стыковки или посадки.

## Запуск

```bash
uv sync
uv run uvicorn main:app --reload --port 8004
```

Сид демо-данных загружается автоматически в пустую базу (`app/seed.py`).
Docs: http://127.0.0.1:8004/docs

## Основные эндпоинты

- `GET/POST /cosmonauts` (+поиск: `name`, `country`, `in_space`, `zodiac`, `station_id`)
- `GET/POST /stations`, `GET /stations/{id}/position?at=`, `PATCH /stations/{id}/oxygen`
- `GET/POST /rockets/types`, `POST /rockets/build`, `POST /rockets/{id}/launch|dock|descend|land`
- `GET/POST /missions`, `POST /missions/{id}/take|complete|cancel`, `PATCH /missions/{id}/status` (канбан)
- `GET /resources`, `POST /resources/deposit`
- `GET /map?at=` — агрегат для страницы «Земля»: все объекты с координатами
