Это самый простой пайтон проект.

Предлагаю создавать их изолированно в отдельных репозиториях

Для создания надо:
1. [Скачать и поставить](https://docs.astral.sh/uv/) `uv` на комп. 
2. Создать директорию `my_backend_project` и войти в нее либо скопировать контент из другой
3. `uv init`
4. `uv sync` (хотя он сам по идее запустится при запуске)
5. Для запуска `uv run file.py`
6. Добавить зависимость - `uv add fastapi`. Она добавится в pyproject.toml, где ее можно контролировать
